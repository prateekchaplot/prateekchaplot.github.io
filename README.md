# Prateek Chaplot — Personal Website

Source for [prateekchaplot.github.io](https://prateekchaplot.github.io/), a personal portfolio built with plain HTML, CSS, and JavaScript.

## Project files

- `index.html` — page content, metadata, and structured data
- `style.css` — responsive layout, typography, and light/dark themes
- `script.js` — theme toggle, mobile navigation, and current year

## Run locally

Open `index.html` in a browser, or serve the project directory with any static file server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

The site is configured as a GitHub Pages user site. GitHub Pages can publish the repository's root branch directly; there is no build step or package installation.
